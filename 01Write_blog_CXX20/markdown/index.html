Markdown 中文手册

本文汇总 Markdown 基础语法、Ametrine 主题组件、HTML 扩展元素和本站常用写法。代码块保持原样，其余说明、示例文字、表格和提示统一使用中文。

主要参考：

  • Ametrine 官方演示
  • Ametrine 官方网站
  • Zola 官方文档
  • Markdown Guide

一、基础语法

1.1 标题

使用一个到六个 # 表示不同层级的标题。标题与文字之间应留一个空格。

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

1.2 段落与换行

段落之间使用空行分隔。Zola 会把这些文本识别为独立段落。

第一段文字。

第二段文字。

如果需要在同一段中强制换行，可以在行末使用 <br/>。

第一行文字
第二行文字

1.3 强调与删除线

**粗体**
_斜体_
~~删除线~~
_**粗斜体**_

实际效果：粗体、斜体、删除线、粗斜体。

强调标记也可以组合使用，例如 加粗且包含 斜体。

1.4 引用块

在段落前添加 > 可以创建引用块，添加多个 >> 可以创建嵌套引用。

这是一段普通的引用内容。

这是嵌套引用，可以在其中继续使用加粗、列表等 Markdown 语法。

  • 引用中的列表项一
  • 引用中的列表项二

1.5 GitHub 提示块

本站启用了 GitHub 风格的提示块，支持 NOTE、TIP、IMPORTANT、WARNING 和 CAUTION。

适合补充背景信息，或说明阅读时容易忽略的细节。

适合提供能提高效率的实用建议。

适合强调完成任务所必需的信息。

适合说明可能导致错误或数据损坏的风险。

适合提示高风险操作或需要特别谨慎的内容。

1.6 列表

无序列表

无序列表可以使用 -、* 或 +。同一个列表中应保持分隔符一致。

- 第一项
- 第二项
  - 嵌套项一
  - 嵌套项二
- 第三项
  • 第一项
  • 第二项
    • 嵌套项一
    • 嵌套项二
  • 第三项

有序列表

1. 执行第一步
2. 执行第二步
3. 执行第三步
  1. 执行第一步
  2. 执行第二步
  3. 执行第三步

任务列表

- [ ] 待完成事项
- [x] 已完成事项
  • 整理文章结构
  • 校对中文说明
  • 验证组件示例
  • 补充后续内容

1.7 代码

行内代码使用反引号包裹，例如 printf("你好")。

多行代码使用三个反引号，并可在开头标注语言：

let highlight = true;

还可以指定行号、起始行和重点行：

10pre mark {
12  display: block;
13  color: currentcolor;
14}
15
17  // 行号使用较弱的颜色
18  color: #6b6b6b;
19  font-style: italic;
20}

在单独一行使用三个或更多 *、- 或 _ 可以生成水平线。

1.10 脚注

正文中使用 [^1] 标记脚注，在文章末尾通过相同标识补充说明[1]。

这是一段带脚注的文字[^1]。

二、链接与媒体

2.1 行内链接

使用 [显示文字](URL "悬浮提示") 创建链接。悬浮提示应使用英文引号。

[Zola 官网](https://www.getzola.org "静态站点生成器")

实际效果：Zola 官网。

2.2 自动链接

使用尖括号可以自动识别网址或电子邮件地址。

<https://www.getzola.org>
<example@example.org>

https://www.getzola.org

example@example.org

2.3 引用式链接

引用式链接把地址统一定义在文章其他位置，便于反复引用同一资源。

[Zola 官方网站][zola]

[zola]: https://www.getzola.org

实际效果：Zola 官方网站。

2.4 标准图片

![图片说明](图片路径 "图片悬浮提示")

如果图片与文章位于同一目录，可以直接填写文件名：

图片也可以作为链接：

[![图片说明](图片路径)](链接地址)

2.5 下载文件

使用带 download 属性的链接可以明确表示这是一个下载入口：

<a class="card" id="file-csv" href="playlist.csv" download>下载 playlist.csv</a>

下载 playlist.csv

如果图片能与文件一起被正确索引，下载入口通常会显示得更完整。

2.6 自定义标题 ID

在标题末尾添加花括号形式的自定义 ID，可以固定锚点名称。

#### 自定义标题 {#custom-id}

自定义标题

通过井号链接可以跳到该标题：

[跳转到自定义标题](#custom-id)

跳转到自定义标题

其他页面也可以使用完整地址加锚点链接到这里。

三、Ametrine 主题组件

Ametrine 提供多种 Tera 组件，用于嵌入媒体、增加提示、展示图片和构建交互内容。

3.1 提示组件

自定义提示组件支持图标、标题和颜色：

  • 必填参数：icon、title
  • 可选参数：color
  • 可用颜色：red、orange、yellow、green、blue、purple
{% <alert icon="warning" title="示例警告" color="blue"> %}
这是一条自定义提示。

- 提示内可以包含列表
- 也可以包含[行内链接](https://example.org)

{% </alert> %}

这是一条自定义提示。

  • 提示内可以包含列表
  • 也可以包含行内链接

3.2 图片组件

图片组件比标准 Markdown 图片提供更多版式选项。

参数说明
url图片地址
url_min压缩图片地址，点击后打开原图
alt图片替代文字
full强制占满可用宽度
start / end让图片在段落起始或结束位置浮动
pixels使用最近邻算法缩放，适合像素画
has_alpha移除圆角和阴影，适合透明图片
drop_shadow使用投影而不是盒阴影
no_hover禁止悬停缩放
spoiler默认模糊，悬停或点击后显示
{{ <image src="graph.png" alt="折线图" class="no-hover"/> }}

也可以不使用组件，而是在普通图片地址后追加锚点：

  • #full：占满宽度
  • #start、#end：浮动到段落起始或结束位置
  • #pixels：像素画清晰缩放
  • #has-alpha：移除圆角和阴影
  • #drop-shadow：使用投影
  • #no-hover：禁止悬停缩放
  • #spoiler：默认模糊
  • #spoiler#solid：完全遮挡，交互后显示
![像素风格图片](image.png#pixels#has-alpha#no-hover)

3.3 视频组件

视频组件支持多个视频源，并可设置自动播放、控制条、循环、静音和行内播放。

{{ <video sources={["video.webm"]} alt="示例视频" controls={true}/> }}

常用属性：

  • autoplay：自动播放
  • controls：显示控制条
  • loop：循环播放
  • muted：默认静音
  • playsinline：在支持的浏览器中尽量行内播放

3.4 CRT 终端风格

CRT 组件适合展示纯装饰性 ASCII 图形。为屏幕阅读器提供 label 后，组件才会暴露说明。

{% <crt label="三角形 ASCII 图形"> %}
  /\
 /  \
/____\
{% </crt> %}

/\
/ \
/____\

也可以在代码块开头添加 crt=true：

```crt=true
  /\
 /  \
/____\
```

页面启用 extra.audio_button = true 后，可以插入带悬停动画的音频按钮。

{{ <audio name="播放效果" url="party-horn.mp3"/> }}

实际效果： 。

3.6 YouTube 视频

YouTube 组件使用隐私增强域名 youtube-nocookie.com。

{{ <youtube id="0Da8ZhKcNKQ"/> }}

可选参数：

  • autoplay：是否自动播放
  • start：从第几秒开始播放

3.7 Vimeo 视频

中国地区暂时无法使用， 直接忽视

{{ <vimeo id="869483483"/> }}

可选参数：autoplay。

3.8 Bilibili 视频

该标题跳转是 {title-bilibili} 使用 bilibili 组件嵌入 B 站视频。参数表中的 {true} 与 {false} 是 Tera 布尔值，不是字符串。

参数默认值说明
id必填BVID 或 av 号
page1分 P 序号
high_qualitytrue请求平台允许的高画质
danmakufalse是否显示弹幕
as_widetrue是否使用 16:9 宽屏布局
autoplayfalse是否自动播放
start0从第几秒开始播放
posterfalse播放前是否显示封面
{{ <bilibili id="BV1VDtk6jEpa" page={1} danmaku={true} start={60}/> }}

画质由 B 站根据账号和平台策略决定。默认不自动播放；如需与组件行为一致，应在粘贴的 iframe 地址后追加 &autoplay=0。

3.9 网易云音乐

该标题跳转 是 {title-netease_music} 使用数字歌曲 ID 嵌入网易云官方外链播放器。

参数默认值说明
id必填数字歌曲 ID
autoplayfalse是否尝试自动播放
{{ <netease_music id="3443840079"/> }}

也可以粘贴官方 iframe：

<iframe
  frameborder="no"
  border="0"
  marginwidth="0"
  marginheight="0"
  width="369"
  height="86"
  src="//music.163.com/outchain/player?type=2&id=1394601255&auto=0&height=66"
>
</iframe>

官方外链播放器不提供歌词显示。播放可能需要登录，部分内容也可能受地区限制。浏览器还可能阻止自动播放。

3.10 横向溢出容器

当表格或代码块明显宽于正文时，可以使用溢出容器提供水平滚动。

{% <overflow_auto overshoot_row={true}> %}
| 很长的表格内容 |
| --- |
| 示例 |
{% </overflow_auto> %}

参数：

  • overshoot：增加垂直方向视觉留白
  • overshoot_row：增加水平方向视觉留白

五、专题与扩展

5.1 图表与 UML

当前文章暂未内置 UML 渲染器。如需在构建阶段生成图表，需要额外引入兼容的 JavaScript 库或 Zola 短代码。

引入第三方渲染器时，必须同步更新 CSP 的 script-src 或 style-src，否则浏览器会阻止资源加载。

5.2 编写建议

  • 标题层级保持连续，避免从一级直接跳到四级。
  • 代码块标注正确语言，便于高亮和搜索。
  • 图片必须提供有意义的替代文字。
  • 外部链接尽量使用可读的中文标签。
  • 交互组件应同时验证浅色、深色和移动端布局。
  • 修改主题组件参数时，应同步检查本文示例。
